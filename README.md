# 🐍 PixiJS Bunny Snake

An arcade-style Snake game built with **PixiJS v8**. Help the bunny eat eggs to grow, but don't hit the walls or yourself!

## 🎮 How to Play
- **Arrow Keys**: Move the Bunny.
- **Spacebar**: Pause/Resume the game.
- **Wrap Mode**: Toggle whether the bunny can pass through walls to the other side.
- **Reset**: Restart the game at any time.

## ✨ Features
- **Dynamic Graphics**: Smooth rendering using PixiJS.
- **Orientation Awareness**: The Bunny and body parts rotate and flip to face the direction of movement.
- **Responsive Design**: The game board centers and resizes based on your browser window.
- **Pulsing Animations**: Visual feedback on the food (eggs).

## 🛠️ Built With
- [PixiJS](https://pixijs.com/) - The HTML5 Creation Engine.
- JavaScript (ES6+).
- HTML5/CSS3.
